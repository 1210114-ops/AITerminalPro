# AI Terminal Pro

Open `AITerminalPro.xcodeproj` in Xcode 16 or later, select an iOS 17+ simulator/device or macOS 14+ destination, then build and run. Xcode creates the deployable `AITerminalPro.app` product.

The project has no third-party packages. Supply your own OpenAI or Gemini API key at runtime; it is only held in memory and is never embedded in the project.
